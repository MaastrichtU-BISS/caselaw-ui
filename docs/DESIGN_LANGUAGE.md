# Design language

The active contract is [DESIGN.md](../DESIGN.md), derived from Bizzy's design
system. The new package uses warm neutral surfaces, BISS blue, compact controls,
restrained borders and explicit state feedback. Host applications can override
semantic tokens on a wrapper and supply their own copy, icons and domain data.

See the [component reference](components.md) for customization and the
[extraction inventory](bizzy-inventory.md) for each source component's disposition.
The renamed caselaw API remains available in this new package; its old public
page layouts are not the visual authority for the extracted Bizzy components.
