# Component guide

Generated by scripts/generate-docs.mjs. BISS UI ships 140 components in each framework, in two tiers.
See [architecture](architecture.md) for package boundaries and state ownership, and the
[documentation site](https://bissui.wicker.life) for live examples and source-derived APIs.

## Components

### Actions

Keep one primary action per task. Use quiet controls for secondary work, and provide a specific accessible name for every icon-only action.

- [BissButton](api.md#bissbutton): A clear action with an explicit visual priority.
- [BissEditableText](api.md#bisseditabletext): Edit a value where it stands, with Enter to save and Escape to cancel.
- [BissHeaderAction](api.md#bissheaderaction): One labelled icon action in a page header.
- [BissToolButton](api.md#bisstoolbutton): A quiet toolbar control with active state, count and a separate clear action.
- [BissToolNew](api.md#bisstoolnew): A primary create action with a menu for other ways to add.
- [BissToolSearch](api.md#bisstoolsearch): A compact toolbar search that expands into an editable query.
- [BissToolbar](api.md#bisstoolbar): A wrapping row for related page tools and trailing controls.

### Forms

Give every control a visible label. Keep values in host state, validate before saving, and put recovery text beside the field.

- [BissCheckbox](api.md#bisscheckbox): A labelled checkbox with optional description text.
- [BissCopyField](api.md#bisscopyfield): A value that can be read, selected and copied without changing it.
- [BissDateField](api.md#bissdatefield): A compact date trigger with a calendar in a floating panel.
- [BissDatePicker](api.md#bissdatepicker): Select a day or a range, type a date, or navigate the calendar by keyboard.
- [BissField](api.md#bissfield): A label, hint or error around a control, with a scoped identifier.
- [BissFilePicker](api.md#bissfilepicker): Choose files or drop them onto the field.
- [BissInput](api.md#bissinput): A single-line value with normal form attributes and validation styling.
- [BissNumberField](api.md#bissnumberfield): Number Field for the team’s everyday work.
- [BissRadioGroup](api.md#bissradiogroup): Choose one option from a short, visible list.
- [BissSearchInput](api.md#bisssearchinput): A search field with the input contract and search treatment.
- [BissSegmentedControl](api.md#bisssegmentedcontrol): Switch between a few mutually exclusive views or modes.
- [BissSelect](api.md#bissselect): The native select for simple browser-driven choice.
- [BissSelectPicker](api.md#bissselectpicker): A searchable dropdown with groups, disabled choices and keyboard navigation.
- [BissSlider](api.md#bissslider): Slider for the team’s everyday work.
- [BissSwatchPicker](api.md#bissswatchpicker): Choose a named color from the workspace palette.
- [BissSwitch](api.md#bissswitch): A labelled on/off setting using the model contract.
- [BissTagInput](api.md#bisstaginput): Add and remove short labels using the model contract.
- [BissTextarea](api.md#bisstextarea): A multiline form value with normal field attributes and validation styling.
- [BissToggleGroup](api.md#bisstogglegroup): Toggle Group for the team’s everyday work.
- [BissValuePicker](api.md#bissvaluepicker): Search and select multiple filter values, with optional negation.

### Overlays

Use an overlay for a focused choice or task. Provide a clear title, preserve keyboard focus and return focus when the task ends.

- [BissConfirmDialog](api.md#bissconfirmdialog): An explicit confirmation before a consequential action.
- [BissDialog](api.md#bissdialog): Connected dialog parts with managed focus, nested layers and a shared visual recipe.
- [BissFigureHelp](api.md#bissfigurehelp): Explain how a figure is calculated, next to the figure.
- [BissMenu](api.md#bissmenu): Searchable actions, checked choices and nested groups in a floating panel.
- [BissModal](api.md#bissmodal): The modal API, for consumers migrating an existing dialog.
- [BissPopover](api.md#bisspopover): A small panel for a choice that needs more room than a menu.
- [BissSearchPalette](api.md#bisssearchpalette): Find a record or action in a focused, searchable dialog.
- [BissSidePanel](api.md#bisssidepanel): Keep a record’s details in view without leaving the surrounding work.
- [BissTooltip](api.md#bisstooltip): A short label for a control, shown on hover and focus.

### Navigation

Keep navigation in a predictable order and let the host router own destinations and permissions.

- [BissAccordion](api.md#bissaccordion): Accordion for the team’s everyday work.
- [BissBreadcrumbs](api.md#bissbreadcrumbs): Show where a page sits in the hierarchy and link back up.
- [BissDisclosure](api.md#bissdisclosure): Hide secondary detail behind a labelled toggle.
- [BissNavItem](api.md#bissnavitem): A navigation destination with optional active state and metadata.
- [BissNavSection](api.md#bissnavsection): Group related navigation destinations under a small heading.
- [BissPagination](api.md#bisspagination): Pagination for the team’s everyday work.
- [BissTab](api.md#bisstab): A navigation tab that can render as a native button or a router link.
- [BissTablePager](api.md#bisstablepager): Previous and next page controls with a live range announcement.
- [BissTabs](api.md#bisstabs): Tabs for the team’s everyday work.
- [BissViewTabs](api.md#bissviewtabs): Switch a page’s view while keeping labels, counts and disabled states consistent.

### Data display

Use display-ready names and values. Display components do not fetch records or decide who may see them.

- [BissAvatar](api.md#bissavatar): Initials on a stable color derived from a person’s name.
- [BissBadge](api.md#bissbadge): A compact status or category label with optional dot and tone.
- [BissCard](api.md#bisscard): A quiet surface that groups one related set of content.
- [BissCodeBlock](api.md#bisscodeblock): Readable highlighted code with a copy action.
- [BissCodeTabs](api.md#bisscodetabs): Keep related language samples together and copy the active one.
- [BissDataTable](api.md#bissdatatable): Sortable columns, pagination and explicit loading and empty states.
- [BissIcon](api.md#bissicon): Bizzy’s authored SVG vocabulary, sized and stroked consistently.
- [BissKbd](api.md#bisskbd): Kbd for the team’s everyday work.
- [BissPeopleCell](api.md#bisspeoplecell): Show a small set of assigned people, with overflow summarized by count.
- [BissPresenceStack](api.md#bisspresencestack): A quiet, overlapping group of people currently on a page.
- [BissPropertyList](api.md#bisspropertylist): Display a record’s labelled properties in a compact description list.
- [BissRecordChip](api.md#bissrecordchip): A small labelled reference to a record, optionally linked.
- [BissSeparator](api.md#bissseparator): Separator for the team’s everyday work.
- [BissServiceIcon](api.md#bissserviceicon): The product marks, or a short text mark supplied by the host.
- [BissStatusCell](api.md#bissstatuscell): A written status reinforced by a colored dot or soft tint.
- [BissTableAddRow](api.md#bisstableaddrow): A quiet row-level action for adding a record to the current group.
- [BissTableGroup](api.md#bisstablegroup): A collapsible group with a name, count and actions around table content.
- [BissTableHead](api.md#bisstablehead): A column heading with a host-owned three-state sort action.
- [BissTableTotal](api.md#bisstabletotal): A compact label and formatted total for a table footer or group summary.

### Charts

State what a figure means. Include labels and units in nearby copy, and use color as reinforcement rather than the only signal.

- [BissBarChart](api.md#bissbarchart): A compact request-style bar chart with an optional highlighted sub-series.
- [BissCapacityBar](api.md#bisscapacitybar): Allocated capacity against availability, with explicit overload feedback.
- [BissChartLegend](api.md#bisschartlegend): Name the colors and line treatments used by a chart.
- [BissGoalBar](api.md#bissgoalbar): A progress track with an optional expected-progress marker.
- [BissGroupedBars](api.md#bissgroupedbars): Compare series within categories and open the records behind each bar.
- [BissLineChart](api.md#bisslinechart): A compact trend from host-provided numeric values.
- [BissMeterList](api.md#bissmeterlist): Compare labelled values on a shared horizontal scale.
- [BissMiniChart](api.md#bissminichart): A decorative schematic for choosing a chart type.
- [BissStackedBar](api.md#bissstackedbar): Parts of a whole in one horizontal bar, with a legend.

### Feedback

Keep messages calm, specific and actionable. Distinguish loading, empty, error and access states instead of presenting a generic blank panel.

- [BissAlertLine](api.md#bissalertline): One quiet line that names a concern and points toward a useful action.
- [BissCallout](api.md#bisscallout): A highlighted note that explains context or a consequence.
- [BissEmptyState](api.md#bissemptystate): Explain why the area is empty and what someone can do next.
- [BissHomeSkel](api.md#bisshomeskel): Quiet loading placeholders shaped like the content that is coming.
- [BissLiveStatus](api.md#bisslivestatus): Quiet connection feedback only when the application is reconnecting or offline.
- [BissNoAccess](api.md#bissnoaccess): Explain restricted access and provide a useful next step.
- [BissPageHint](api.md#bisspagehint): A keyboard-accessible explanation that stays out of the page’s main reading path.
- [BissProgress](api.md#bissprogress): Progress for the team’s everyday work.
- [BissSaveBar](api.md#bisssavebar): Bring unsaved changes, recovery and save actions into one place.
- [BissSkeleton](api.md#bissskeleton): Simple content-shaped bars for loading layouts.
- [BissSpinner](api.md#bissspinner): Spinner for the team’s everyday work.
- [BissToastStack](api.md#bisstoaststack): Render the application-wide toast queue after an action.

## Blocks

### Application shells

The shell frames the page; the host router owns navigation, the signed-in account and permissions.

- [BissAppShell](api.md#bissappshell): An application frame with navigation, a working area and optional account furniture.
- [BissBottomBar](api.md#bissbottombar): A shared footer for ownership, help and policy links.
- [BissConsoleLayout](api.md#bissconsolelayout): A ready-made console frame with sidebar, page heading and account area.
- [BissGridShell](api.md#bissgridshell): The public-page frame with a shared top bar and footer.
- [BissSidebarUser](api.md#bisssidebaruser): The signed-in identity with account navigation and sign-out actions.
- [BissSplitPane](api.md#bisssplitpane): Two resizable panes, such as a list beside its detail.
- [BissTopBar](api.md#bisstopbar): The shared brand and primary navigation bar.

### Page headers

Keep the page title, context, view navigation and actions in a predictable order across pages.

- [BissConsoleHeader](api.md#bissconsoleheader): A compact console heading with breadcrumbs, context and actions.
- [BissPageBar](api.md#bisspagebar): A page title, context, actions and view navigation in one compact header.
- [BissPageHeader](api.md#bisspageheader): The page title and subtitle, with an actions slot.
- [BissSectionHeader](api.md#bisssectionheader): Introduce a content section and place its actions alongside the title.
- [BissSettingsHead](api.md#bisssettingshead): A settings section’s title, one-line explanation and optional extra detail.

### Data views

Pass only the records the person may see. The host owns persistence, permissions and domain calculations; these blocks render data and emit intent.

- [BissAgenda](api.md#bissagenda): A meeting agenda: timed items to add, reorder and tick off.
- [BissCalendar](api.md#bisscalendar): Dates and deadlines in a month grid, with an agenda on phones.
- [BissColumnManager](api.md#bisscolumnmanager): Show, hide, pin, reorder and resize the columns of a table.
- [BissDataGrid](api.md#bissdatagrid): A spreadsheet-like table with selection, pinning, sorting and resizable columns.
- [BissFilterBuilder](api.md#bissfilterbuilder): Compose filter rules with fields, operators and values.
- [BissKanban](api.md#bisskanban): Group cards into lanes and move them by dragging or keyboard selection.
- [BissLabelEditor](api.md#bisslabeleditor): Create, rename, recolor and remove the labels of a field.
- [BissTaskList](api.md#bisstasklist): Tasks with completion, owner, due date and status.
- [BissTimeline](api.md#bisstimeline): Show inclusive date spans clipped to the visible time window.

### Sharing and collaboration

These blocks show and edit who can do what. The host resolves identities, checks permissions and persists every change.

- [BissAccessList](api.md#bissaccesslist): Who can open a record, with their role and how they got access.
- [BissActivityList](api.md#bissactivitylist): A chronological list of who changed what, with optional detail.
- [BissCommentComposer](api.md#bisscommentcomposer): Write a comment, mention people and submit with the keyboard.
- [BissCommentThread](api.md#bisscommentthread): A discussion on a record, with a composer and resolve state.
- [BissNoticeRow](api.md#bissnoticerow): A notification row with unread state, context and a host-owned action.
- [BissPresenceCursor](api.md#bisspresencecursor): Another person’s cursor, labelled with their name and color.
- [BissRecordPreview](api.md#bissrecordpreview): A compact preview of a linked record, or a notice when it is restricted.
- [BissRoleEditor](api.md#bissroleeditor): Define roles and the permissions each one grants.
- [BissSharePanel](api.md#bisssharepanel): Invite people, set their role and manage a public link.

### Dashboards

Each widget answers one question. Name the figure, explain it in a line, and offer one next action.

- [BissDataTile](api.md#bissdatatile): A dashboard tile that frames a figure, a chart or a list.
- [BissDeadlineList](api.md#bissdeadlinelist): Dated items ordered by urgency, with overdue items called out.
- [BissGoalCard](api.md#bissgoalcard): A goal with its progress, expected pace and owner.
- [BissHomeCard](api.md#bisshomecard): The shared widget anatomy: name, explanation, content and one action.
- [BissKpiCard](api.md#bisskpicard): One headline figure with the label and note needed to interpret it.
- [BissQuickLinks](api.md#bissquicklinks): A compact grid of frequent destinations.
- [BissStatList](api.md#bissstatlist): A compact list of labelled counts or formatted values.
- [BissSummaryStrip](api.md#bisssummarystrip): A row of labelled figures, with supporting notes and optional color markers.
- [BissWidgetGrid](api.md#bisswidgetgrid): Arrange dashboard widgets in a grid that people can reorder by drag or keyboard.

### Documents

Document blocks render host-provided content. Sanitize rich text before passing it in and keep links explicit.

- [BissAttachmentList](api.md#bissattachmentlist): Files attached to a record, with links and a remove action.
- [BissBookmark](api.md#bissbookmark): A rich link preview with title, description and source.
- [BissDocumentCallout](api.md#bissdocumentcallout): A tinted note block inside a document.
- [BissDocumentToc](api.md#bissdocumenttoc): A document outline that tracks the heading in view.
- [BissMediaFigure](api.md#bissmediafigure): An image or video with caption and credit.
- [BissProposalCard](api.md#bissproposalcard): A suggested change that someone can review before applying.

### Onboarding

Ask for the smallest useful choice at each step. Completion and progress belong to the application, so people can leave and return safely.

- [BissChecklist](api.md#bisschecklist): A labelled set of completion steps controlled by the host application.
- [BissOnboardingChips](api.md#bissonboardingchips): Choose several interests or areas during workspace setup.
- [BissOnboardingFrame](api.md#bissonboardingframe): A compact setup task with a title, progress and actions.
- [BissStep](api.md#bissstep): One completed, current or upcoming step in an ordered setup flow.
- [BissSteps](api.md#bisssteps): An ordered container that gives setup steps a shared reading rhythm.

### Marketing

Public-page compositions: keep copy short and specific, and give each section one clear action.

- [BissActionCard](api.md#bissactioncard): A linked surface for choosing a destination, available in both frameworks.
- [BissFeatureCard](api.md#bissfeaturecard): Describe one capability, using the service mark and supporting copy.
- [BissHero](api.md#bisshero): The public-page heading with supporting copy and optional actions.
- [BissHeroPill](api.md#bissheropill): A small piece of supporting context in a public-page heading.
